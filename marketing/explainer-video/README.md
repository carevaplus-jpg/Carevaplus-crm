# Careva+ — "Care That Comes Home" explainer

A 63-second motion graphics film that explains **what Careva+ is, why it matters, and who it is for**, built around the Careva+ logo.

| Spec | Value |
|---|---|
| Output | `careva-explainer.mp4` — 1920×1080, 16:9, 30 fps, H.264 + AAC |
| Duration | 63 s |
| Music | Original ambient score generated by `music.py` (80 BPM; every cut lands on a beat) |
| Sound-off | Yes: the full story is told in on-screen type |

## Concept

**"Care that comes home."** A thin green-to-blue thread, taken from the logo's leaf veins, runs through the film. It underlines the hook, draws the house, links the people the service is for, and closes under the tagline. The film starts cool and tired (hospital trips), turns at night (*What if care came home?*), and then a lit doorway opens into the bright Careva+ world.

## Editing the film

All copy lives in `careva-explainer.html`:
- Services: the `SERVICES` array
- Audiences: `WHO`
- Reasons: `WHY`
- Care-journey steps: `STEPS`
- Headlines: inline in the scene markup

Scene timings are in the `T` object and the `seek(t)` function. Open the HTML file through any local web server to preview it live.

## Re-rendering

```bash
cd marketing/explainer-video
node render.js /tmp/frames 30 4                 # frames (Playwright + Chromium)
python3 music.py /tmp/score.wav                 # music (numpy)
ffmpeg -framerate 30 -i /tmp/frames/f_%05d.jpg -i /tmp/score.wav \
  -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p -c:a aac -b:a 192k \
  -af loudnorm=I=-14:TP=-1.5 -shortest -movflags +faststart careva-explainer.mp4
```
