## How to use this

1. **Paste the style block at the end of every prompt.** It is what makes the
   whole set look like one photographer shot it, instead of eleven unrelated
   stock photos. This matters more than any single prompt.
2. Generate them in the priority order below — the first three carry most of
   the visual weight.
3. Don't worry about exact pixel sizes. Get the shape roughly right and the
   cropping, resizing and compression is handled here.
4. Save each file with the filename given, so they can be slotted straight in.

## The style block — append to every prompt

```
Photorealistic documentary photograph. Natural soft window light, warm and
calm, hopeful but understated. Set in a middle-class South Indian home in Tamil
Nadu — simple tiled floors, plain painted walls, cotton curtains, everyday
furniture. South Indian people. Shallow depth of field, 35mm lens look, gentle
neutral palette with soft green and blue tones. Respectful and dignified, never
staged or cheerful-stock. Absolutely no text, no words, no lettering, no logos,
no watermarks, no medical branding, no visible brand names.
```

## If ChatGPT gets the people wrong

Common fixes to add to the prompt:

- Hands come out malformed → "hands clearly visible and anatomically correct"
- Looks too Western → "South Indian faces and clothing, Tamil Nadu setting"
- Too glossy → "documentary realism, natural skin texture, no retouching"
- Adds text or logos → "no text anywhere in the image, no signage"
- Uniform looks wrong → "plain pale-teal scrub top, no badges or insignia"

## One thing to be clear about

These will be AI-generated images, not photographs of your actual staff or
patients. They work well as illustrative imagery, and that is normal practice.
Just don't caption them as real Careva+ nurses or real clients — if a family
later meets a different person, that erodes exactly the trust the site is
built to earn. When you can, replacing these with real photographs of your own
team (with their consent) will always outperform them.
